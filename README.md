# Week 7 Assignment: My Notes & The Report Builder

- `my_notes.py`: Writes, appends to, reads, and counts lines in `my_notes.txt`.
- `my_notes.txt`: Text file containing the four saved notes generated by `my_notes.py`.
- `report_builder.py`: Reads learner scores from `hubs.csv`, handles missing files safely, and writes summary statistics to `report.txt`.
- `hubs.csv`: Input CSV dataset listing learner names, hubs, and scores.
- `report.txt`: Output summary report generated by `report_builder.py` showing total, passed, failed, and average scores.

## What if `"a"` were changed to `"w"` in Question 1?

Changing `"a"` (append mode) to `"w"` (write mode) when adding the fourth note would erase the existing contents of `my_notes.txt` before writing `"I added this later\n"`. As a result, the file would only contain that single line instead of all four notes.
